Autonomous trading assistant with natural language instructions, multi-layer policy enforcement, risk-aware validation, and a safe broker integration architecture. Powered by GPT-4o intent parsing and Alpaca paper trading.

**Stack:** FastAPI · Python · OpenAI GPT-4o · Alpaca Markets · Pydantic · JSONL Audit Logs · Next.js Frontend
